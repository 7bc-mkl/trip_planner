# D03 — The first version is a manual timeline; chat adds and changes items
- Date, owner: 2026-09-05, Michal Klosinski
- Context and the options weighed: Three options for the smallest first version were offered: (a) a manual timeline with statuses and attachments where chat only adds and changes items, (b) chat generating a draft plan from dates and a destination, (c) an inbox that arranges uploaded reservations onto a timeline.
- Decision and why: Option (a): "zdecydiwanie a". The plan is built by hand; chat is an editing surface, not a generator.
- Consequences, and what would make us revisit it: The timeline, its statuses and its counter are the product's core and get built first. Whole-trip generation is not in the first version. Assumption A02 (chat beats direct editing) stays open and is tested against this decision.
- Required path to change: A superseding record; moving to (b) would change what the first screens are for.
