Illustrative mockup for .ai/specs/2026-09-05-trip-sharing-magic-link.md — the two guest error pages, rendered in English because R01 makes both locales first-class. Full pages with the same chrome and the locale switch, because the recipient has nowhere else to go in this application. The distinction is deliberate: a revoked link says so; an unknown or deleted one does not claim the owner made a decision he did not make.

A third state, not pictured: when the backend is unreachable the guest sees a retry state — never an empty timeline, which would be indistinguishable from a genuinely empty plan and would be a lie about it.
