Smart Trip Planner Language PLEN

Three states, kept apart deliberately. BACKWARD_COMPATIBILITY.md §3 requires a shared itinerary link to keep resolving or resolve to an explicit “no longer available”, never to a wrong plan — and a deleted plan must not be reported as a sharing decision the owner never took. Each is a full page with the same chrome and the same locale switch, because the recipient has nowhere else to go in this application.

🔒

This plan is no longer shared

The person who planned this trip has turned the link off. If you still need to see the plan, ask them for a new link.

410 · share_link_revoked

Trip deleted · HTTP 410

🗺

This plan no longer exists

The trip this link pointed to has been deleted. The link itself was genuine — there is simply nothing left to show.

410 · share_link_gone

Unknown or malformed link · HTTP 404

🔗

This link does not work

The link may have been copied incompletely. Check the message you received, or ask the sender for the link again.

404 · share_link_not_found

A fourth state is not pictured: when the backend is unreachable the guest sees the retry state the walking skeleton already specifies — never an empty timeline, which would be indistinguishable from a genuinely empty plan and would be a lie about it.
